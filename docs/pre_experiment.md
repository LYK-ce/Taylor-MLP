# 预实验：Taylor-MLP 可行性验证

## 1. 实验目标

验证 K-means 聚类展开点 + 一阶泰勒展开近似 MLP 前向传播的**精度**。核心问题：欧氏距离聚类确定的展开点，其局部一阶泰勒近似能否替代原始 MLP 的完整前向传播？

## 2. 实验配置

### 2.1 网络结构

采用升维-降维的现代 MLP 结构（模拟 Transformer FFN）：

| 层 | 维度变换 | 激活 |
|----|---------|------|
| Linear 1 | 64 → 256 | ReLU |
| Linear 2 | 256 → 512 | ReLU |
| Linear 3 | 512 → 256 | ReLU |
| Linear 4 | 256 → 64 | - |

输入 64 维，输出 64 维，参数量 ~329K。小规模以快速迭代。

### 2.2 数据

- 训练集：随机生成 10,000 个 64 维向量，服从标准正态分布 N(0,1)
- 测试集：同分布生成 2,000 个向量
- 标签：通过 MLP 前向输出获得（自监督，比较的是近似输出 vs 真实输出）

### 2.3 K-means 展开点

| 超参数 | 取值 |
|--------|------|
| k（展开点数） | 1, 2, 4, 8, 16, 32, 64, 128 |
| 聚类数据 | 训练集输入特征 |

### 2.4 Jacobian 计算

使用 PyTorch autograd 在每个展开点 $X_0^{(i)}$ 处计算 Jacobian 矩阵 $J(X_0^{(i)}) = \frac{\partial F}{\partial X}\big|_{X=X_0^{(i)}}$。

对 64 维输入 × 64 维输出的网络，每个 Jacobian = 64×64 = 4096 个元素。

## 4. 实验步骤

### Step 1：构建并训练/初始化 MLP

- 定义上述 4 层 MLP
- 初始化权重（默认 PyTorch 初始化即可，或训练至收敛）

### Step 2：生成数据

- 生成 10,000 训练样本 + 2,000 测试样本（64 维）
- 通过 MLP 前向计算获得真实输出

### Step 3：K-means 聚类选取展开点

- 对 10,000 训练样本的输入特征进行 K-means
- 取 k ∈ {1, 2, 4, 8, 16, 32, 64, 128}
- 记录聚类中心 $\{X_0^{(1)}, ..., X_0^{(k)}\}$

### Step 4：预计算展开点信息

对每个展开点 $X_0^{(i)}$：
- 计算 $F(X_0^{(i)})$（一次前向传播）
- 计算 $J(X_0^{(i)})$（autograd 求导）
- 存入字典

### Step 5：推理与精度评估

对测试集中每个样本 $X$：
1. 计算与各展开点的欧氏距离，取最近 $X_0^{(c)}$
2. 泰勒近似：$\hat{F}(X) = F(X_0^{(c)}) + J(X_0^{(c)}) \cdot (X - X_0^{(c)})$
3. 计算误差：相对于真实输出 $F(X)$ 的 **MSE** 和 **余弦相似度**

### Step 6：对比分析

- 绘制 k vs MSE 曲线
- 绘制 k vs 余弦相似度曲线
- 分析精度收敛趋势

## 5. 评估指标

| 指标 | 含义 |
|------|------|
| MSE | 原始输出与近似输出的均方误差，越小越好 |
| Cosine Similarity | 输出向量方向一致性，越接近 1 越好 |
| 存储比 | Taylor-MLP 存储量 / 原始模型存储量 |
| 推理加速比（理论） | 原始 MAC / Taylor MAC |

## 6. 实验输出

所有实验结果文件存放于 `Result/Pre_Experiment/` 目录：

- `k_vs_mse.csv`：不同 k 下的 MSE
- `k_vs_cosine.csv`：不同 k 下的余弦相似度
- `accuracy_plot.png`：精度曲线图
- 实验结论摘要 `README.md`

## 7. 成功标准

- 存在某个 k 使得余弦相似度 > 0.95 且存储 ≤ 原始模型
- 若无法达到，记录最大精度及对应 k，分析失败原因

# Phase 2: CNN + Taylor-MLP on MNIST

## 1. 实验目标

在真实数据集 MNIST 上验证 Taylor-MLP 方案。将 CNN 中的 MLP 分类器替换为一阶泰勒近似，评估对最终**分类准确率**的影响。

## 2. 实验配置

### 2.1 网络结构

```
CNN Backbone (特征提取):
  Conv2d(1, 16, 3, pad=1) → ReLU → MaxPool(2)   # 16×14×14
  Conv2d(16, 32, 3, pad=1) → ReLU → MaxPool(2)   # 32×7×7 = 1568

MLP Classifier (被Taylor替代的部分):
  Linear(1568, 256) → Activation → Linear(256, 64) → Activation → Linear(64, 10)
```

- CNN backbone 保持原样（不做近似）
- 仅对 MLP Classifier 做 Taylor 近似
- MLP 参数量: 1568×256 + 256×64 + 64×10 = **418,432**

### 2.2 Taylor-MLP 存储

每个展开点存储: $J$ (10×1568) + $F(X_0)$ (10) + $X_0$ (1568) = 17,258 参数

| k | Taylor 参数 | 存储比 |
|----|------------|--------|
| 6 | 103,548 | 24.8% |
| 12 | 207,096 | 49.5% |
| 24 | 414,192 | 99.0% |
| 48 | 828,384 | 198.0% |

### 2.3 对比激活函数

- ReLU（预期差，Phase 1 已证实）
- GELU
- SiLU

### 2.4 评估指标

| 指标 | 含义 |
|------|------|
| 分类准确率 | 近似输出 argmax vs 真实标签 |
| CosSim | MLP 输出向量 vs 真实 MLP 输出 |
| MSE | MLP 输出向量 MSE |

## 3. 实验步骤

### Step 1：训练 CNN

- 在 MNIST 训练集 (60K) 上训练上述 CNN
- 达到 >98% 验证准确率

### Step 2：提取特征

- 用 CNN backbone 提取所有训练/测试样本的 1568 维特征向量
- 同时记录 MLP 的真实输出

### Step 3：K-means 聚类

- 对训练集特征进行 K-means（k ∈ {1, 4, 8, 12, 24, 48, 96}）
- 聚类中心作为展开点

### Step 4：预计算 Jacobian

- 在每个展开点处计算 MLP 的 $F(X_0)$ 和 $J(X_0)$

### Step 5：Taylor 推理

- 对测试集每个样本，找最近展开点，应用一阶泰勒近似
- 取 argmax 作为预测类别

### Step 6：对比分析

- 各激活函数下，k vs 分类准确率
- k vs CosSim / MSE
- 与原始 CNN 准确率对比

## 4. 成功标准

- 存在 k 使得分类准确率下降 < 2%（相对原始 CNN）
- 且存储 ≤ 原始 MLP (k ≤ 24)
